# Adeba Studio website

## Preview
Open index.html after extracting the ZIP. No build tools or dependencies are needed.

## Publish on GitHub Pages
Create a public repository named `AdeRoastED.github.io` (if it already exists, inspect it and back it up first; do not overwrite blindly). Upload the contents of this folder, including the assets folder, to its root. Under Settings → Pages, choose Deploy from a branch, main, / (root), then Save. The intended site address is https://aderoasted.github.io/. This package has not been published.

## Before launch
- Verify existing app preview links against the latest builds. No Google Play store links are fabricated.
- Replace the Noise Smuggler provisional icon and Animal Friends temporary graphic when the final art is ready.
- Add official social URLs after creating the accounts. TimerMask's existing YouTube channel is linked.
- Check the website privacy notice against actual hosting and email practices; prepare app-specific policies from the final app builds and SDK/data practices before publishing the apps.
- Obtain the real AdMob publisher line and follow app-ads-SETUP.txt. Do not publish a fake app-ads.txt.
- If using a different hosting address, update the sitemap, robots.txt, Open Graph image URLs and 404 home link.

Artwork is supplied from the conversation and existing game ZIPs; concept art is explicitly labeled. The site has no analytics or advertising scripts.
